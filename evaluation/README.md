# 评测案例

`cases/` 保存按“公司 + 报告期”组织的案例与标签。当前新增的 600519、000858 两份 2024 年案例均为真实年报的财务披露事实参考，状态是 `agent_provisional_pending_human`，尚未人工复核，也未分配 train/validation/test 集。

标签只记录四项指标在原年报中的 2024/2023 比较列及证据页码，不是人工 golden、异常标签、舞弊标签或无舞弊结论。原文 PDF 与解析文本存放在 `data/raw/`、`data/processed/`，未确认再分发许可；不得把评测标签混入分析材料或模型检索上下文。CLI 结果和弃权以案例中的 run_id 为准，提取失败不能解释为指标为零。
