# 开发协作

本文件说明人与执行端如何分工。规则原文仍是根目录 [AGENTS.md](../AGENTS.md)。本文件不替代它，也不改变角色限制。

## 分工

主控 agent 负责项目架构和项目计划，包括实现策略与方向、需求理解、方案策划、任务拆解、验收标准、结果审查及对用户汇报。主控可以直接做只读检查和验收，不限定型号。

gpt-6-luna（max）作为子代理负责具体执行，包括编码、文件修改和运行验证。接到任务后直接实施。未经用户或主控明确安排，不转派，也不另开执行端。

实施任务仅通过当前会话提供的子代理机制分配给 gpt-6-luna（max），不通过外部终端或独立执行会话替代。主控写明任务范围、文件归属和验收要求。派发前以当前会话信息或明确的子代理配置核对模型及推理强度；无法确认或启动指定配置的子代理时如实说明，不擅自改用其他模型或执行方式。

子代理完成后由主控审阅实际改动、验收证据及路线一致性；偏差或测试失败先在同一任务内修正、复核。任务审查通过后，下一项实施任务启动新的 gpt-6-luna（max）子代理，不沿用旧任务上下文。

该分工只用于项目开发。项目默认云端模型供应方仍由用户配置。2026-09-28 已在用户明确授权下读取 CC Switch `claude/DeepSeek` 官方直连凭据，完成海天 603288 2024 单例在线验收；不读取其他工具的密钥，也不把本次临时供应方设为默认值。
