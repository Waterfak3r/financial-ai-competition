# FINTRACE 路线

时间按关卡排列，不承诺日期。首版不做 OCR、向量库、GraphRAG、模型训练、用户系统和云部署。计划书与视频独立，不在这些关卡里。

保留现有模块，不搬迁目录。新增年度分析任务与旧预检分开。本地单进程同时只跑一个活动任务，重启后把未完成任务标成中断失败。报告保留缺口。原文、计算和引用要能回溯。

流程目标是：提取、事实核验、确定性计算与筛查、解释与调查、主张核验、报告。补充检索最多一次。

核验必须重读 PDF，不能复用提取阶段已经做出的最终行列判断。状态为 verified、conflict、insufficient_evidence。追溯状态未知时不默认可比。零或负基数只保留差额，增速弃权。非经常性损益披露合计不直接除以归母净利润。主张分为 fact、calculation、inference、hypothesis。同比是 calculation。模型自评不能代替独立核验。未验证内容进入待核查区。

## 测试

测试发现应覆盖 integration、golden 和 regression。M1 起注入错金额、错单位、错年度列、错口径和无证据主张。M4 对相同候选比较有核验与无核验，报告错误检出、误拦截、漏检、弃权、覆盖和耗时。人工答案与分析材料隔离，只放在评测标签区。
