# FINTRACE 技术里程碑

本文维护工程能力与完成条件；[产品交付路线](product-delivery-roadmap.md)负责从可录原型、初赛材料到决赛成品的任务顺序。两者是不同视角，不是两套并行开发指令；具体工作以用户当前任务为准。以下状态整理于 2026-10-01，历史证据集中在 [验收记录](verification-history.md)。

## 里程碑

| 关卡 | 已实现与已验证范围 | 尚需满足的条件 |
| --- | --- | --- |
| M0 文档基线 | 已有规则、入口、架构、数据与路线；本次按职责整理，移除重复历史状态 | 随实际变更维护所属文档，不再向所有入口复制验收流水 |
| M1 事实与可比性 | 海天 2024 单样例独立核验 8 条事实；依据同一报告的披露确认年度可比性 | 新公司/期间另验收；未与此前单独披露的 2023 年报独立勾稽 |
| M2 确定性闭环 | 海天单样例完成 8 项计算、16 条确定性 Claim 核验与 2 条候选；CLI、任务 API、报告与证据入口已接通 | 不据单样例声称通用提取或跨公司分析 |
| M3 规则与模型调查 | 五类扩展字段、四条试行规则；LangGraph 调查、限量同源检索、调用审计；候选解释有历史在线单例；最终评审与设置入口已实现并经 mock 检查 | 真实在线最终评审未验收；阈值未校准；规则二语义映射仅支持海天该版式；多公司与人工评测待完成 |
| M4 展示与可靠性评测 | Evidence Explorer 已接通；单公司七案例有/无独立核验消融基线存在；茅台/五粮液有 provisional 事实参考 | 3–5 家公司人工 golden、多公司消融、误报/漏报/弃权/覆盖率与耗时统计未完成 |
| M5 多期间 | 半年报、季报和环比尚未实现 | 产品路线中的决赛扩展目标另建期间/口径/跨文件核验与验收，不是当前功能承诺 |

M3 筛查和 AI 调查是当前互斥的模式；有四规则代码不代表每次 AI 运行都执行四规则。海天四规则总分为零只表示该次有限规则未触发，不表示公司无风险。

## 与产品交付的衔接

按 [产品路线任务表](product-delivery-roadmap.md#6-可执行任务)逐项实施和验收：先解决可录原型的有效信息、主要发现与证据查看，以及实际 AI 流程的验收缺口；再推进多公司评测、交付包装和目标扩展。路线中的排期是建议，不是比赛通知，也不授权一次性重构。

工程验收应同时回答：是否已有代码、是否接入实际入口、是否完成指定样例/范围的验证。CLI 通过不替代 Web 验收，mock 通过不替代在线调用，历史回放不替代新运行，多份 PDF 不等于多公司完整分析。

## 保持的核心契约

- 核验重新读取 PDF，不直接复用提取器的最终行列判断；事实、计算、模型观点分开。
- 未知币种、单位、期间、口径或可比性时弃权；非正比较基数不计算增长率，缺失不当作零。
- 当前进程签发的 proof 只在该进程授权；序列化副本只作审计。普通 VerificationResult 对象不是签名凭据。
- 调查限于本次同源年报，补充检索最多一次；最终评审仍是观点，引用绑定不证明语义正确。
- 旧预检与 v2 分开且兼容历史读取，不补写历史上未执行的核验。
- 多公司 provisional 案例不能冒充人工 golden；受控错误测试不能替代真实异常识别评测。
